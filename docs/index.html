Notes

These notes record interpretation constraints and data handling choices so readers can understand assumptions behind the displayed results.

  • Only values present in source files are displayed; unknown values remain blank.
  • Main summary metrics exclude old-results by default.
  • _ns and no-service query identifiers are treated as "no service descriptions".
  • Experiment-family display mapping: EX1 -> NOINDEX-ASK, EX2 -> NOINDEX-COUNT, EX3 -> VOID-TRIPLE, EX4 -> VOID-BLOCK, and matching -NRL variants.
  • Overview and Monthly sections are collapsible.
